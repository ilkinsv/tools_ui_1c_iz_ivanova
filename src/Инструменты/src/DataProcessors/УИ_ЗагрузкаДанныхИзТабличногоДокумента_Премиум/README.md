**Версия:** 2.0  
**Платформа:** 1С:Предприятие 8.3.18–8.3.27 / 8.5.1+  
**Конфигурация:** УНФ 3.0.12.199 (совместимо с УТ 11.5 / ERP 2.5 через адаптацию метаданных)

---

## 🎯 Назначение

Высокопроизводительная обработка для загрузки данных из табличных документов (Excel, MXL, CSV) в справочники и регистры сведений 1С. Оптимизирована для работы с большими объёмами данных (до 50 000 строк).

### Ключевые преимущества перед оригиналом из `tools_ui_1c`:

- ⚡ **Скорость ×5–10** благодаря кэшированию в памяти и пакетным транзакциям
- 🔒 **Надёжность транзакций** с откатом при ошибках
- 🏷️ **Поддержка характеристик номенклатуры** УНФ
- 🎨 **Улучшенный UX** с авто-маппингом и предпросмотром
- 📊 **Встроенный бенчмарк** производительности

## 🔧 Режимы загрузки реквизитов

| Режим | Описание | Поведение |
|-------|----------|-----------|
| `НеИспользовать` | Пропуск колонки | Колонка игнорируется при загрузке |
| `ЗагружатьСуществующие` | Обновление | Поиск по ключам → обновление реквизитов |
| `СоздаватьЕслиНет` | Создание + обновление | Поиск → создание при отсутствии → запись |

## 🚀 Быстрый старт

### 1. Установка

Скопируйте файлы обработки в вашу конфигурацию:

```bash
# Для EDT
cp -r src/Инструменты/src/CommonModules/УИ_ЗагрузкаДанных_Сервер.bsl <путь_к_проекту>/src/cfe/CommonModules/
cp -r src/Инструменты/src/DataProcessors/УИ_ЗагрузкаДанныхИзТабличногоДокумента_Премиум <путь_к_проекту>/src/cfe/DataProcessors/
```

### 2. Настройка маппинга

1. Откройте обработку
2. Выберите файл Excel/MXL/CSV
3. Проверьте автоматический маппинг колонок
4. При необходимости отредактируйте соответствие

### 3. Запуск загрузки

1. Выберите режим загрузки (`СоздаватьЕслиНет` или `ЗагружатьСуществующие`)
2. Нажмите кнопку **"Загрузить данные"**
3. Дождитесь завершения операции

## ⚙️ Технические детали

### Детектор версии платформы

Обработка автоматически определяет возможности платформы:

- **Индексы ТЗ** (8.3.12+) – ускоренный поиск в кэшах
- **Пакетная запись** (8.3.15+) – оптимизированная фиксация транзакций
- **Быстрый парсер ТД** (8.3.24+) – ускоренное чтение файлов
- **Параллельные задания** (8.5.1+) – фоновая обработка

### Алгоритм обработки

```
1. Инициализация
   ├─ ПолучитьВозможностиПлатформы()
   ├─ ПодготовитьКэшиУНФ() (одним запросом)
   └─ Создать индексы ТЗ (если 8.3.12+)

2. Парсинг файла
   ├─ ТД.Прочитать()
   ├─ ТЗ.ИмпортКолонки(Область)
   └─ Статистика.Всего = ТЗ.Количество()

3. Пакетная обработка (цикл по строкам, шаг = 500)
   ├─ НачатьТранзакцию()
   ├─ Для каждой строки:
   │   ├─ Сформировать КлючПоиска
   │   ├─ Найти в КэшНоменклатуры
   │   ├─ Если НеНайдено И Режим=СоздаватьЕслиНет → СоздатьНоменклатуру()
   │   ├─ Если Найдено И Режим=ЗагружатьСуществующие → ОбновитьРеквизиты()
   │   ├─ Если ЦелевойОбъект="Характеристика" → Найти/СоздатьХарактеристику()
   │   └─ Записать в ТЗ.ЛогиОшибок при исключении
   ├─ Если ПакетЗавершён → ЗафиксироватьТранзакцию()
   └─ Иначе → Продолжить

4. Завершение
   ├─ ОтменитьТранзакцию() при глобальной ошибке
   ├─ Вернуть Статистика (Всего, Успешно, Создано, Ошибки)
   └─ ОтключитьОбновлениеИнтерфейса(Ложь)
```

## 🚫 Запрещённые паттерны

В коде обработки **не используются**:

- ❌ `Выполнить()`, `Оценка()` – динамическое создание переменных
- ❌ `Справочники.Номенклатура.НайтиПоКоду()` внутри циклов
- ❌ `Запрос.Выполнить().Выбрать()` построчно для каждой строки файла
- ❌ Изменение структуры `ТаблицаЗначений` внутри циклов обработки
- ❌ `Сообщить()` в серверном цикле без буферизации
- ❌ Жёсткая привязка к 8.3.24+ без фолбэков для 8.3.18

## 🧩 Расширение функциональности

### Добавление поддержки других справочников

Для расширения обработки на другие справочники:

1. Откройте `УИ_ЗагрузкаДанных_Сервер.bsl`
2. Найдите процедуру `ПодготовитьКэшиУНФ()`
3. Добавьте новый кэш по аналогии с `КэшНоменклатуры`
4. Обновите функцию `АвтоматическийМаппингЗаголовков()`

### Пример добавления справочника "Контрагенты":

```bsl
// В процедуру ПодготовитьКэшиУНФ()
КэшКонтрагенты = Новый ТаблицаЗначений();
КэшКонтрагенты.Колонки.Добавить("Ссылка", Новый ОписаниеТипов("СправочникСсылка.Контрагенты"));
КэшКонтрагенты.Колонки.Добавить("ИНН", Новый ОписаниеТипов("Строка(12)"));
КэшКонтрагенты.Колонки.Добавить("КПП", Новый ОписаниеТипов("Строка(9)"));

Если ИндексыПоддерживаются Тогда
    КэшКонтрагенты.Индексы.Добавить("КлючКонтр", Массив("ИНН", "КПП"));
КонецЕсли;

ЗапросКонтр = Новый Запрос;
ЗапросКонтр.Текст = 
    "ВЫБРАТЬ
    |   Контрагенты.Ссылка КАК Ссылка,
    |   Контрагенты.ИНН КАК ИНН,
    |   Контрагенты.КПП КАК КПП
    |ИЗ
    |   Справочник.Контрагенты КАК Контрагенты";

РезультатКонтр = ЗапросКонтр.Выполнить();
Если РезультатКонтр <> Неопределено Тогда
    КэшКонтрагенты = РезультатКонтр.Выгрузить();
КонецЕсли;
```

## 📞 Поддержка

При возникновении проблем:

1. Проверьте логи ошибок в таблице формы
2. Убедитесь, что права доступа позволяют создание/изменение объектов
3. Проверьте, что справочник "Номенклатура" существует в конфигурации
4. Убедитесь, что используется платформа 8.3.18 или выше
