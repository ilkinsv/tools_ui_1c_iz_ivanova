## Описание

**Универсальный Инструмент Управления Версиями 7.0.3** - это комплексное решение для управления версиями проектов на платформе 1С:Предприятие с полной поддержкой системы расширений.

### Ключевые особенности версии 7.0.3:

1. **Система версионирования с уникальным шагом**
   - Минорная версия увеличивается на 99 (X.99.YYY)
   - Патч-версия от 0 до 999
   - Полная история изменений

2. **Мощная система расширений**
   - Простое создание расширений
   - Точки расширения (hooks)
   - Управление зависимостями между расширениями
   - Реестр расширений

3. **Адаптивность и кроссплатформенность**
   - Поддержка Windows x86/x64
   - Поддержка Linux x86/x64
   - Совместимость с MacOS (не тестировалось)
   - Работа на платформе 8.3.12+

4. **Встроенная система логирования**
   - Многоуровневое логирование
   - Запись в файл
   - Буферизация сообщений

5. **Управление конфигурацией**
   - Сохранение/загрузка конфигурации в JSON
   - Проверка совместимости платформ
   - История версий

## Быстрый старт

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/cpr1c/tools_ui_1c.git

# Перейдите в директорию проекта
cd tools_ui_1c

# Запустите сборщик

```

### Использование

#### Базовое использование

```bsl
#Использовать "СистемаВерсий7.0.3"

// Создание менеджера версий
МенеджерВерсий = СоздатьМенеджерВерсий();
МенеджерВерсий.ИнициализироватьВерсию(7, 0, 3, "Основной релиз");

// Получение текущей версии
ТекущаяВерсия = МенеджерВерсий.ПолучитьТекущуюВерсию();
Сообщить(ТекущаяВерсия.СтрокаВерсии()); // v7.0.3

// Обновление версии
НоваяВерсия = МенеджерВерсий.СледующаяПатчВерсия();
Сообщить(НоваяВерсия.ПолнаяВерсия()); // 7.0.4
```

#### Работа с расширениями

```bsl
#Использовать "СистемаВерсий7.0.3"

// Создание реестра расширений
РеестрРасширений = СоздатьРеестрРасширений();

// Создание расширения
Расширение = СоздатьРасширение("my.extension", "Моё расширение", "1.0.0");
Расширение.Автор = "Разработчик";
Расширение.Описание = "Описание расширения";

// Добавление точек расширения
Расширение.ДобавитьТочкуРасширения("ПриЗапуске", 
    "Сообщить(""Расширение запущено!"");");

// Регистрация расширения
РеестрРасширений.ЗарегистрироватьРасширение(Расширение);

// Вызов точек расширения
РеестрРасширений.ВызватьТочкуРасширения("ПриЗапуске");
```

#### Логирование

```bsl
#Использовать "СистемаВерсий7.0.3"

Логгер = СоздатьЛоггер();
Логгер.УстановитьФайлЛога("/path/to/log.txt");
Логгер.УстановитьУровень(Логгер.УРОВЕНЬ_ИНФО);

Логгер.ЗаписатьИнфо("Информационное сообщение");
Логгер.ЗаписатьПредупреждение("Предупреждение");
Логгер.ЗаписатьОшибка("Ошибка");
```

## Архитектура

### Компоненты системы

1. **ИнформацияОВерсии** - Класс для хранения информации о версии
   - Номер мажорный, минорный, патч
   - Дата релиза
   - Описание и список изменений
   - Методы сравнения версий

2. **Расширение** - Класс для создания расширений
   - Идентификатор и имя
   - Версия и автор
   - Зависимости
   - Точки расширения

3. **РеестрРасширенийКласс** - Управление расширениями
   - Регистрация расширений
   - Поиск расширений
   - Вызов точек расширения

4. **МенеджерВерсийКласс** - Управление версиями
   - Инициализация версий
   - Обновление версий (патч, минор)
   - Сохранение/загрузка конфигурации
   - Проверка совместимости

5. **ЛоггерКласс** - Система логирования
   - Уровни логирования
   - Запись в файл
   - Буферизация

## Примеры использования

```bsl
Процедура УправлениеВерсиямиПроекта()

    // Сохранение истории
    МенеджерВерсий.СохранитьКонфигурацию("C:\Projects\version_history.json");
    
КонецПроцедуры
```

### Пример 2: Создание плагина

```bsl
Процедура СоздатьПлагин()
    
    РеестрРасширений = СоздатьРеестрРасширений();
    
    // Плагин валидации кода
    ПлагинВалидации = СоздатьРасширение("code.validator", "Валидатор кода", "1.0.0");

        "ПроверитьКодНаОшибки();");
    ПлагинВалидации.ДобавитьТочкуРасширения("ПослеКомпиляции", 
        "ВыполнитьСтатическийАнализ();");
    
    РеестрРасширений.ЗарегистрироватьРасширение(ПлагинВалидации);
    
    // Плагин документирования
    ПлагинДокументирования = СоздатьРасширение("doc.generator", "Генератор документации", "2.99.001");
    ПлагинДокументирования.ДобавитьЗависимость("code.validator", "1.0.0", Неопределено);
    
    РеестрРасширений.ЗарегистрироватьРасширение(ПлагинДокументирования);
    
КонецПроцедуры
```

## Структура версий

### Формат версий

```
X.YYY.ZZZ
│ │   │
│ │   └─ Патч версия (0-999)
│ └─── Минорная версия (шаг 99)
└───── Мажорная версия
```

### Примеры корректных версий

- 7.0.3 - Начальная версия
- 7.0.250 - Патч обновление
- 7.99.0 - Минорное обновление
- 7.99.500 - Патч после минорного
- 7.198.0 - Следующее минорное
- 8.0.0 - Мажорное обновление

## API Reference

### ИнформацияОВерсии

| Метод | Описание |
|-------|----------|
| `Установить(Мажорный, Минорный, Патч, Описание, Дата)` | Установка параметров версии |
| `ПолнаяВерсия()` | Возвращает строку версии в формате "X.Y.Z" |
| `СтрокаВерсии()` | Возвращает строку версии в формате "vX.Y.Z" |
| `Больше(ДругаяВерсия)` | Сравнение версий |
| `Равна(ДругаяВерсия)` | Проверка равенства версий |
| `ДобавитьИзменение(Тип, Описание)` | Добавление записи об изменении |

### Расширение

| Метод | Описание |
|-------|----------|
| `Установить(Идент, Имя, Версия, Автор, Описание)` | Инициализация расширения |
| `ДобавитьЗависимость(Идентификатор, МинВерсия, МаксВерсия)` | Добавление зависимости |
| `ДобавитьТочкуРасширения(Имя, Обработчик)` | Регистрация точки расширения |
| `ПолучитьТочкуРасширения(Имя)` | Получение обработчика точки |
| `ПроверитьЗависимости()` | Проверка всех зависимостей |

### РеестрРасширений

| Метод | Описание |
|-------|----------|
| `ЗарегистрироватьРасширение(Расширение)` | Регистрация расширения |
| `РасширениеСуществует(Идентификатор)` | Проверка существования |
| `ПолучитьРасширение(Идентификатор)` | Получение расширения по ID |
| `ВызватьТочкуРасширения(Имя, Параметры)` | Вызов точки расширения |
| `КоличествоРасширений()` | Количество зарегистрированных |

### МенеджерВерсий

| Метод | Описание |
|-------|----------|
| `ИнициализироватьВерсию(Мажорный, Минорный, Патч, Описание)` | Инициализация версии |
| `ПолучитьТекущуюВерсию()` | Получение текущей версии |
| `СледующаяПатчВерсия()` | Увеличение патч версии |
| `СледующаяМинорнаяВерсия()` | Увеличение минорной версии (+99) |
| `СохранитьКонфигурацию(Путь)` | Сохранение в JSON |
| `ЗагрузитьКонфигурацию(Путь)` | Загрузка из JSON |
| `ПроверитьСовместимостьПлатформы(Версия)` | Проверка платформы |

### Логгер

| Метод | Описание |
|-------|----------|
| `УстановитьУровень(Уровень)` | Установка уровня логирования |
| `УстановитьФайлЛога(Путь)` | Установка файла лога |
| `ЗаписатьОшибка(Сообщение)` | Запись ошибки |
| `ЗаписатьПредупреждение(Сообщение)` | Запись предупреждения |
| `ЗаписатьИнфо(Сообщение)` | Запись информации |
| `ЗаписатьОтладка(Сообщение)` | Запись отладочной информации |

## Точки расширения

Система поддерживает следующие стандартные точки расширения:

- `ПриЗапуске` - Вызывается при запуске системы
- `ПередЗакрытием` - Вызывается перед закрытием
- `ПередСохранением` - Перед сохранением данных
- `ПослеЗагрузки` - После загрузки конфигурации
- `ПриОбновленииВерсии` - При обновлении версии

Вы можете регистрировать свои собственные точки расширения.
